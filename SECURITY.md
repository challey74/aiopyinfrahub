# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Instead, report
them privately through
[GitHub's private vulnerability reporting](https://github.com/challey74/aiopyinfrahub/security/advisories/new).

You should receive a response within a week. Please include a description
of the issue, steps to reproduce, and the affected version.
